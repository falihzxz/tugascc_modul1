Pengenalan Cloud Computing Oleh Falih

Memahami konsep dasar komputasi awan, model arsitektur layanan, serta platform penyedia cloud terkemuka di dunia industri modern.

📖 1. Apa Itu Cloud Computing?

Definisi dan karakteristik fundamental komputasi awan

Cloud Computing (Komputasi Awan) adalah teknologi penyediaan sumber daya komputasi—seperti server fisik/virtual, penyimpanan data (storage), database, jaringan, dan perangkat lunak—secara on-demand (sesuai kebutuhan) melalui koneksi internet.

Pengguna tidak perlu lagi membeli dan mengelola server fisik sendiri di gedung atau ruangan khusus (on-premise), melainkan cukup menyewa infrastruktur yang disediakan oleh penyedia cloud dengan skema Pay-As-You-Go (bayar sesuai penggunaan).

⚡ Efisiensi Biaya

Menghemat modal awal pembelian hardware mahal dan biaya maintenance server.

📈 Skalabilitas Tinggi

Kapasitas server dapat dinaikkan atau diturunkan dengan cepat saat traffic meningkat.

🌍 Akses Global

Aplikasi dan data dapat diakses dari mana saja secara real-time melalui internet.

🛡️ Keandalan & Backup

Data terlindungi dengan pusat data redundan dan sistem disaster recovery otomatis.

⚙️ 2. Jenis Model Layanan Cloud

Tiga kategori utama layanan komputasi awan berdasarkan tingkat kontrol pengguna

🖥️

IaaS

Infrastructure as a Service

Menyediakan infrastruktur dasar komputasi berupa virtual machine, server, storage, dan jaringan. Pengguna memiliki kontrol penuh atas sistem operasi, aplikasi, dan konfigurasi sistem.

Contoh Layanan: AWS EC2, Azure Virtual Machines, Google Compute Engine (GCE).
📦

PaaS

Platform as a Service

Menyediakan lingkungan pengembangan dan deployment aplikasi. Pengguna hanya perlu fokus membuat dan mengunggah kode program tanpa perlu mengurus sistem operasi atau server.

Contoh Layanan: AWS Elastic Beanstalk, Azure App Service, Google App Engine, Heroku.
🌐

SaaS

Software as a Service

Perangkat lunak yang siap digunakan langsung oleh pengguna akhir via web browser atau aplikasi, tanpa instalasi rumit maupun pengelolaan infrastruktur latar belakang.

Contoh Layanan: Google Workspace (Gmail, Drive), Microsoft 365, Dropbox, Zoom.

🏢 3. Contoh Penyedia Layanan Cloud (Cloud Providers)

Tiga raksasa teknologi penyedia infrastruktur cloud global (The Big Three)

🟧

Amazon Web Services

AWS
Pangsa Pasar #1

Pionir layanan cloud publik komersial sejak 2006 dengan katalog layanan terlengkap dan jaringan data center terluas di dunia.

  • Komputasi: Amazon EC2
  • Penyimpanan: Amazon S3
  • Database: Amazon RDS, DynamoDB
🟦

Microsoft Azure

Azure
Solusi Enterprise

Layanan cloud dari Microsoft dengan integrasi sempurna untuk sistem Windows Server, Active Directory, serta solusi hybrid cloud perusahaan.

  • Komputasi: Azure Virtual Machines
  • Penyimpanan: Azure Blob Storage
  • Deployment: Azure App Service
🟥

Google Cloud Platform

GCP
AI & Big Data

Layanan cloud dari Google yang sangat unggul dalam pemrosesan data skala besar, container (Kubernetes), serta teknologi kecerdasan buatan (Machine Learning).

  • Komputasi: Compute Engine, Cloud Run
  • Penyimpanan: Cloud Storage
  • Container: Google Kubernetes Engine (GKE)
